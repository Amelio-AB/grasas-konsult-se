# Engströms Konsulter
## Projektdefinition och designriktning

Status: Första kunddemo
Senast uppdaterad: 2026-08-10

---

# 1. Projektets syfte

Projektet ska skapa en responsiv one-page-webbplats för Engströms Konsulter.

Den första versionen är främst en visuell kunddemo som ska användas för att:

- visa en möjlig grafisk riktning
- visa föreslagen sidstruktur
- konkretisera företagets erbjudande
- ge kunden något tydligt att reagera på
- skapa en teknisk grund för den framtida webbplatsen

Detta är ännu inte den slutliga produktionsversionen.

Prioriteringsordning:

1. visuell kvalitet
2. tydligt budskap
3. konsekvent grafisk identitet
4. responsivitet
5. bra UX
6. enkel och underhållbar kod

Undvik överengineering.

---

# 2. Teknik

Projektet ska byggas med:

- Astro
- Astro-komponenter
- CSS
- minimal JavaScript
- TypeScript där Astro naturligt använder det

Använd inte:

- React
- Vue
- Svelte
- UI-frameworks
- animationsbibliotek

om det inte finns ett tydligt tekniskt behov.

Webbplatsen ska i första hand vara statisk.

- därmed förenlig verksamhet

# 12. Grafisk profil

Den befintliga grafiska profilen och logotypen är huvudreferens för webbplatsens visuella identitet.

Grunduttrycket ska vara:

- mörk kolsvart/blåsvart
- varmvit/off-white
- gul/guldig accent
- mycket whitespace
- modern sans-serif
- tunna linjer
- geometriska former
- teknisk precision
- skandinavisk enkelhet

Gult ska användas sparsamt.

Gult ska fungera som:

- accent
- vägvisare
- aktiv detalj
- hover
- mindre grafiska linjer

Undvik stora gula bakgrundsytor.
