# Engströms Konsulter

Första kunddemon för Engströms Konsulter: en responsiv one-page-webbplats för tjänster inom väg och trafik samt kontorsservice.

## Teknik

- Astro
- TypeScript via Astro
- CSS med centrala design-tokens
- Minimal JavaScript för mobilnavigationen

## Kom igång

```sh
npm install
npm run dev
```

Utvecklingsservern visar adressen i terminalen, normalt `http://localhost:4321`.

## Bygg och kontrollera

```sh
npm run check
npm run build
```

Den statiska produktionsversionen skapas i `dist/`.

## Projektstatus

Detta är en kunddemo. Varumärkesnamn, telefonnummer och e-postadress ska slutbekräftas före produktionspublicering. Projektbriefen finns i `PROJECT.md`.
